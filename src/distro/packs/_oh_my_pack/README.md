# _oh_my_pack

[← Back to the README](../../../../README.md#optional-tooling-packs)

The pack template.

The skeleton a new pack starts from: copy the folder, rename it, fill it in.
Its scripts only say they ran - it installs nothing and provides nothing.

**Type:** template - offered, but installs nothing: copy the folder to start a pack.

## Requires

oh_my_shell.
